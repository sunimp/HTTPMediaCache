HTTPMediaCache Architecture

Swift-only local HTTP media cache: proxy playback, preload, HLS rewrite, byte range storage.

1.0.1 public API surface

入口层

  • • `HTTPMediaCache` 暴露播放、预加载、查询与清理入口
  • • `CacheRuntime` 持有代理、存储、下载器和 HLS 策略
  • • Example 与 XCTest 均通过公开 API 验证行为

数据链路

  • • Proxy 路由播放器请求，按 HLS 与普通媒体分流
  • • Pipeline 将请求拆成本地缓存段和远端下载段
  • • Storage 记录缓存区间并落盘到本地文件

HLS 边界

  • • Playlist 缓存原始内容，播放侧按需改写代理 URL
  • • key、init map、segment 使用独立下载策略
  • • 预加载复用同一套选择、下载和缓存策略
